# Fictional quotation set

These files are public demonstration data for the same 10-laptop purchase. They deliberately use different layouts and commercial terms:

- `northstar-systems-quotation.pdf`: GST is 18% extra, shipping is free, delivery is 7 days, and warranty is 1 year.
- `pixelpeak-supply-quotation.png`: lower unit price, GST is itemized, shipping is INR 2,000, delivery is 15 days, and warranty is 3 years.
- `cedar-office-tech-quote.jpg`: total includes tax but the tax breakdown is unclear, delivery is approximately 10 days, and warranty is 1 year.

All companies, contacts, tax identifiers, and transactions are fictional.

To regenerate the files outside the Codex bundled runtime, install `reportlab` and `Pillow`, then run `python generate_samples.py` from the repository root.
